# KOREA MISSIONARY ARCHIVE — 1권 OCR 완료본

- 원본 PDF 1: 300쪽 / 원본 PDF 2: 299쪽 (총 599쪽 확보)
- **1권 OCR 초벌: PDF 1~300쪽, 300쪽 전체 완료**
- 초기 인물 카드: 79건. 신규 인물 추가는 표제어와 원문 페이지를 대조한 뒤 별도 반영한다.
- 1권 OCR 상태: `ocr_complete_unverified` (초벌 완료·내용 검증 전)

## 데이터 원칙
PDF 뷰어 쪽수와 책 인쇄 쪽수를 구분한다. OCR 결과는 검색과 후보 추출을 위한 초벌이며, 인명·생몰년·교단·내한일·지명·활동 연혁을 확정하는 근거로 단독 사용하지 않는다. 반드시 원문 이미지와 대조한다. 출처에 없는 정보는 추정하지 않으며 미확인 정보는 빈칸 또는 미확인으로 둔다.

## 실행
`index.html`을 브라우저에서 연다. 데이터는 브라우저 localStorage에 저장된다. JSON 백업을 정기적으로 내려받는다. 현재 버전은 로컬 시제품이며 연구팀 실시간 공동 사용에는 인증·서버 DB·권한 관리가 추가로 필요하다.

## 폴더
- `data/initial-people.json`: 초기 인물 데이터 79건
- `ocr/volume1/`: 1권 PDF 1~300쪽 OCR 텍스트 및 매니페스트
- `data-schema.json`: 데이터 구조
- `kma-entry-template.csv`: 추가 입력 양식
